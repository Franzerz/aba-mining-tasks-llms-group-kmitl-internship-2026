BODY GENERATION (Follows Body Decision Log rules):

OFFICIAL BODY DECISION LOG RULES (Apply in order, strictly):
1. Remove intensifiers: "very", "extremely", "really", "quite", "rather", "so", "such"
   Example: "Very clean room" → clean_room
2. Remove plural suffixes "s", "es" if semantically safe

   Example: "staffs" → staff
3. Remove "-ed" endings ONLY if not semantically critical
   Example: "well decorated room" → well_decorated_room (keep if necessary)
4. Remove punctuation: ".", "!", "?"
5. Remove articles ("a", "an", "the") and redundant prepositions
   Example: "a nice room" → nice_room
6. Convert to lowercase
7. Replace spaces with underscores
8. Use ONLY words from original text (NO synonyms, NO external words), except for the required topic noun mapping in Rule 16.
9. Keep phrases SHORT — one noun + one key adjective/verb (unless meanings require split)
10. Correct obvious typos only (else mark as inappropriate)
11. Match sentiment — extract features matching the given sentiment only
12. SPLIT if double meanings exist
    Example: "great modern room" → great_room AND modern_room (two separate entries)
13. SPLIT for multiple meanings into all combinations
14. Create natural noun phrases:
    - If phrase ends with ADJECTIVE: add implied noun — "room is clean" → clean_room
    - If phrase ends with OBJECT/VERB: don't add subject — "close to airport" stays as near_airport
15. HANDLE INDIRECT MEANINGS:
    a) "would be X / should be X / lack of X" → create "no_[X]" — Example: "would like buffet" → no_buffet
    b) "-er comparatives" → "[noun]_could_be_[adjective]" — Example: "pool could be bigger" → pool_could_be_bigger
    c) "couldn't have been more X" → "[X]_[topic]" — Example: "couldn't have been more helpful" → helpful_staff
16. TOPIC-SPECIFIC conversions:
    - Room: If the phrase is a standalone adjective or quality about a room, add _room.
      Example: "clean" → clean_room
    - Facility: If the phrase contains any of {apartment, apartments, hotel, accommodation, accommodations, place, building, atmosphere, property}, replace that word with hotel in the final literal.
      Examples: "new apartments" → new_hotel, "comfortable accommodation" → comfortable_hotel
    - Staff: If the phrase contains any of {people, receptionist, housekeeper, owner, host, gentleman, lady}, replace that word with staff in the final literal.
      Examples: "helpful receptionist" → helpful_staff, "friendly people" → friendly_staff
    - Location: Noise outside (street, beach, bars) → Location; Noise inside (walls, AC) → Room
17. If body duplicates head, use Contrary (opposite) instead
18. Prefer active voice
19. For complex text, extract EACH distinct meaning as separate body

EXTRACTION RULES:
- Extract only characteristics matching the given SENTIMENT (Positive = good/present qualities; Negative = bad/missing qualities)
- One body literal per distinct characteristic (SPLIT if multiple meanings)
- Use ONLY words appearing in the original text
